## Project Objectives

The main objectives of the QuantDB project are:

 1.⁠ ⁠*To design and implement a centralized relational database* for efficiently storing and managing financial market data, securities, users, orders, trades, portfolios, positions, trading strategies, and backtesting results.

 2.⁠ ⁠*To apply core DBMS concepts* such as ER modeling, relational schema design, primary and foreign keys, integrity constraints, normalization, and relationship mapping in a real-world financial application.

 3.⁠ ⁠*To develop meaningful SQL-based operations* for inserting, retrieving, updating, and analyzing financial data using joins, aggregate functions, subqueries, views, and other relational operations.

 4.⁠ ⁠*To improve database performance and demonstrate query optimization* through appropriate indexing, execution-plan analysis, and efficient query design.

 5.⁠ ⁠*To implement transaction management mechanisms* for maintaining data consistency during operations such as simulated order execution, trade creation, and portfolio/position updates.

 6.⁠ ⁠*To demonstrate advanced database functionality* using stored procedures, functions, triggers, and appropriate constraints for automating and validating database operations.

 7.⁠ ⁠*To develop a functional user interface connected to the database* that allows users to view market information, manage simulated trading activities, analyze portfolios, and generate reports.

 8.⁠ ⁠*To integrate a Python-based analytical layer* for processing market data, performing quantitative calculations, and communicating between the application and the relational database.

 9.⁠ ⁠*To implement a basic historical backtesting system* that allows users to evaluate predefined trading strategies using historical market data and simulated transactions.

10.⁠ ⁠*To calculate and report quantitative performance and risk metrics*, including returns, volatility, Sharpe ratio, maximum drawdown, and profit/loss, to support systematic strategy evaluation.

11.⁠ ⁠*To incorporate basic market-microstructure analysis*, such as bid-ask spread, market depth, and order-book imbalance, to provide exposure to concepts relevant to quantitative and algorithmic trading.

12.⁠ ⁠*To provide an integrated platform for database-driven quantitative research*, demonstrating how DBMS concepts can be applied to a realistic financial-market problem.
